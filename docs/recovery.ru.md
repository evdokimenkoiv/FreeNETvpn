# Восстановление резервной копии

[English](recovery.en.md) · [Русский](recovery.ru.md)

Администратор создаёт и скачивает архив на странице **Резервные копии**. На время согласованного снимка сервисы Compose кратко останавливаются; они запускаются снова даже при ошибке архивации. Храните копию вне VPS. Архив содержит секреты: `.env`, сгенерированные настройки `runtime/` и `data/`, включая VPN/прокси-ключи, хеши паролей пользователей и назначения профилей. Исходников в архиве нет: сохраняйте рядом номер развёрнутого Git-коммита.

## Порядок восстановления
1. Подготовьте заменяющую Linux-машину, исходники той же версии и поддерживаемые Docker/Compose. Передайте архив приватно. Перед использованием тех же ключей на замене остановите старый экземпляр.
2. В каталоге исходников `.env`, `runtime/` и `data/` должны отсутствовать или быть пустыми. Восстановление откажется работать поверх существующих данных. Не удаляйте рабочие данные для обхода проверки; для репетиции используйте отдельный чистый каталог.
3. Из этого каталога выполните:
   ```bash
   sudo bash restore.sh /absolute/path/freenetvpn-backup.tar.gz
   sudo python3 tools/manage.py validate
   ```
4. Направьте основной домен и домен WireGuard на новый сервер. Сохранение имён и портов позволяет использовать прежние профили. При смене имён отдельно спланируйте перевыпуск профилей и сертификатов.
5. Запустите восстановленную установку:
   ```bash
   sudo bash install.sh --existing
   sudo bash scripts/health_check.sh
   ```
6. Войдите старым владельцем, проверьте пользователей и назначения, выполните вход обычным пользователем. Проверьте HTTPS, реальный трафик и DNS на внешнем клиенте, отказ отозванным ключам. Сравните состав восстановленных настроек и ключей с архивом.

## Что важно при восстановлении
До распаковки проверяются пути и типы записей: обход каталогов, ссылки и непустое назначение запрещены. Архив должен поступить от доверенного администратора; механизм не шифрует его и не добавляет независимую цифровую подпись. Произвольные файлы хоста, SSH, сторонние правила firewall и внешняя DNS-зона не входят в копию. Старый архив возвращает старые пароли и может вернуть ключи, отозванные после его создания: проверьте и отзовите их повторно.

Успешная распаковка в пустой каталог и совпадение ключей ещё не являются полной репетицией аварийного восстановления. Для неё нужно запустить восстановленную установку и подключить внешние устройства. В кабинете есть памятка и скачивание; кнопки перезаписи работающего сервера нет.
