# Трафик и обслуживание

[Русский](operations.ru.md) · [English](operations.en.md)

Администратору доступны разделы **Трафик** и **Обслуживание**. Обычные пользователи не имеют доступа к этим API. Сбор выполняется каждые 30 секунд; суммарная история скорости хранится до 24 часов и переживает перезапуск агента. Текущие счётчики сервиса сбрасываются при перезапуске контейнера. Прочерк означает отсутствие данных. Для скорости нужны два измерения; сбросы и пропуски разрывают график. Данные закрыты и входят в резервную копию.

| Показатель | Смысл |
| --- | --- |
| RX / TX | Байты на сетевых интерфейсах сервиса с запуска контейнера, включая служебный трафик и обе стороны проксирования. Не подходит для тарификации |
| WireGuard / AmneziaWG | Пиры с handshake за последние 180 секунд; доступ в интернет этим не подтверждается |
| VLESS / Outline / MTProto / HTTP-SOCKS | Установленные входящие TCP-соединения на портах сервиса, а не отдельные люди или подтверждённые сессии. UDP-сессии Outline не подсчитываются |
| IKEv2 / L2TP | Установленные IKE-сессии отдельно; общий трафик IPsec учитывается один раз |

График показывает суммарную скорость сервисов, а не учёт по отдельным пользователям. Ключи, IP-адреса клиентов и история посещений не собираются. Ошибка измерения не останавливает VPN.

Обслуживание показывает свободное место, объём журналов/Docker и запрос ОС на перезагрузку. **Проверить** сравнивает записанную версию исходников с веткой GitHub `main` и выполняет симуляцию APT upgrade по уже имеющемуся локальному индексу. Показывается дата самого старого индекса. Ошибка сети означает «недоступно», а не «обновлений нет». Проверка не обновляет индексы, не устанавливает пакеты, не загружает образы и не перезапускает сервисы. Поиск новых версий образов контейнеров пока не включён. Перед обновлением изучите изменения и сохраните копию вне сервера.

Очистка требует предпросмотра и подтверждения, действующего пять минут. Доступны только две операции:

- **Архивные журналы:** `journalctl --vacuum-time=7d` — архивные системные журналы старше семи дней на всём сервере. Активные файлы сохраняются; принудительной ротации нет.
- **Кэш сборки Docker:** `docker builder prune --force --filter until=168h` — dangling-кэш сборки старше семи дней на всём сервере, включая другие проекты. Без `--all`, удаления образов, контейнеров и томов. Повторная сборка может занять больше времени.

Предпросмотр показывает текущее использование, а не точный объём будущего освобождения. В журнале операции сохраняется свободное место до и после; параллельная запись на сервере может дать отрицательную разницу. Подтверждение одноразовое даже при ошибке; для повтора нужен новый предпросмотр. После перезапуска агента незавершённые задания помечаются прерванными: проверьте результат перед повтором. Профили, ключи, аккаунты, копии, образы и контейнеры сохраняются. Логи Docker ограничены 10 МБ × 3 файла для вновь созданных/пересозданных контейнеров; вручную они не обнуляются. Храните копии вне сервера; [восстановление](recovery.ru.md).
