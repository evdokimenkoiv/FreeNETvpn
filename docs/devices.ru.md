# Инструкции для устройств

[English](devices.en.md) · [Русский](devices.ru.md)

Те же инструкции доступны в кабинете: «Как подключиться». Сначала администратор должен назначить вам профиль.

## iOS / iPadOS

### WireGuard

1. **Установите WireGuard.** Откройте официальный список приложений по ссылке ниже и выберите свою платформу.
2. **Получите свой профиль.** Нажмите «Получить профиль» или кнопку скачивания справа. Сохраните файл .conf.
3. **Добавьте туннель.** В приложении нажмите + и импортируйте .conf либо сканируйте QR с другого экрана. Разрешите добавление VPN-конфигурации.
4. **Включите подключение.** Выберите импортированный туннель и включите его. Не используйте один профиль одновременно на разных устройствах.
5. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://www.wireguard.com/install/).

### VLESS

Выбранный клиент должен поддерживать транспорт профиля: WebSocket/TLS или gRPC/TLS. Для мобильного keep-alive используйте Xray JSON, поскольку URI/QR содержит обычный WS/TLS.

1. **Выберите приложение.** В списке Project X выберите клиент для iOS или вашей архитектуры macOS с нужным транспортом. Доступность приложений зависит от региона.
2. **Добавьте конфигурацию.** Скопируйте строку vless:// из профиля и выберите импорт из буфера обмена; либо используйте QR-код. Xray JSON импортируется как конфигурационный файл в поддерживающий его клиент.
3. **Включите VPN или системный прокси.** Выберите профиль и включите соединение. На компьютере режим системного прокси покрывает только совместимые приложения; для полного туннеля нужен поддерживаемый TUN/VPN-режим. Проверку сертификата TLS оставьте включённой.
4. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://xtls.github.io/en/document/level-0/ch08-xray-clients.html).

### IKEv2

Используйте значения из своего экспорта. Пароль VPN может отличаться от пароля кабинета.

1. **Скачайте параметры.** Распакуйте ZIP. В нём JSON с сервером и учётными данными, ca.pem и профиль .mobileconfig для Apple.
2. **Создайте VPN-подключение.** Откройте .mobileconfig и подтвердите установку в настройках профилей устройства. Перед доверием CA подтвердите его происхождение у администратора.
3. **Проверьте поля.** Сервер и Remote ID должны совпадать с server/remote_id из JSON. Используйте логин и пароль из экспорта, EAP-MSCHAPv2 и доверенный CA. В Windows импортируйте CA в доверенные корневые сертификаты компьютера по правилам вашей организации.
4. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://support.apple.com/guide/deployment/vpn-settings-overview-dep2d2adb35d/web).

### L2TP/IPsec

Используйте значения из своего экспорта. Пароль VPN может отличаться от пароля кабинета.

1. **Скачайте параметры.** Откройте JSON: server — сервер, username/password — аккаунт VPN, ipsec_psk — общий секрет IPsec.
2. **Создайте VPN-подключение.** Откройте настройки VPN устройства и добавьте подключение L2TP/IPsec, если оно поддерживается вашей системой.
3. **Проверьте поля.** Укажите сервер, аккаунт и пароль, а общий секрет — в поле IPsec PSK/Shared secret. Не используйте незащищённый L2TP без IPsec.
4. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://support.apple.com/guide/deployment/vpn-settings-overview-dep2d2adb35d/web).

### Outline

1. **Установите Outline Client.** По официальной ссылке выберите клиент для своего устройства. Outline Manager пользователю не нужен.
2. **Добавьте ключ.** Скопируйте ss:// из профиля. В Outline выберите добавление сервера и вставьте ключ доступа.
3. **Подключитесь.** Нажмите «Подключиться» и подтвердите разрешение VPN, если устройство его запрашивает.
4. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://developer.getoutline.org/download-links/).

### AmneziaWG

Нужен совместимый AmneziaWG-клиент с поддержкой S1–S4 и H1–H4. Обычное приложение WireGuard не подходит.

1. **Установите совместимый клиент.** Используйте официальный сайт Amnezia и проверьте совместимость версии приложения с экспортированным профилем.
2. **Импортируйте файл.** Скачайте .conf и добавьте его в AmneziaWG через импорт туннеля. На телефоне можно использовать QR-код из кабинета.
3. **Подключитесь.** Разрешите VPN-конфигурацию и активируйте туннель. После изменения шаблона скачайте и импортируйте профиль заново.
4. **Проверьте подключение.** Откройте сайт и проверьте внешний IP и DNS. Если приложение показывает подключение, а сайты не открываются, сообщите администратору. Индикатор VPN сам по себе не доказывает передачу трафика.

[Официальная инструкция / загрузка](https://docs.amnezia.org/documentation/instructions/use-amneziawg-app/).

### Telegram MTProto

MTProto работает только в Telegram. Это не VPN для остальных приложений. Роутер настраивать не нужно: добавьте прокси в Telegram на каждом устройстве.

1. **Установите Telegram.** Используйте официальное приложение Telegram для iOS, Android, macOS или Windows. Веб-версия не использует этот профиль.
2. **Откройте ссылку профиля.** Скопируйте ссылку tg://proxy из выданного профиля и откройте её на нужном устройстве. Либо в настройках Telegram найдите «Прокси», выберите MTProto и перенесите server, port и secret из ссылки.
3. **Подключитесь и проверьте.** Подтвердите использование прокси. Дождитесь подключения и проверьте загрузку сообщений и медиа. Звонки и другие приложения могут использовать иной маршрут. Не публикуйте секретную ссылку.

[Официальная инструкция / загрузка](https://telegram.org/apps).

### HTTP / SOCKS5

HTTP CONNECT и SOCKS5 требуют логин и пароль; UDP отключён. Сам транспорт прокси не шифруется: в недоверенной сети используйте его через VPN. HTTPS сохраняет шифрование содержимого сайта. Доступ к внутренним адресам сервера закрыт.

1. **Откройте JSON.** server — адрес; http_port — порт HTTP; socks5_port — порт SOCKS5. username и password относятся к прокси и отличаются от входа в кабинет.
2. **Выберите место настройки.** Для HTTP: Настройки → Wi-Fi → ваша сеть → Настройка прокси → Вручную; включите аутентификацию. Это настройка этой Wi-Fi-сети, не сотовой связи. SOCKS5 задавайте в поддерживающем его приложении.
3. **Проверьте приложение.** Откройте HTTPS-сайт и проверьте внешний IP именно в настроенном приложении. Для SOCKS5 включите разрешение DNS через прокси, если клиент это поддерживает. При ошибке 407 проверьте логин и пароль.

[Официальная инструкция / загрузка](https://curl.se/docs/manpage.html).
