# Decisions and alternatives

Decision: pin released Specify CLI 1.0.6 and generate Codex native skills with Python helpers. The upstream generator prefers an existing .venv interpreter, which can bake Windows paths into shared files; the checked-in portable skills and their manifest were therefore generated in a clean staging project where python was on PATH, using the unmodified CLI. Preserve the existing constitution. A stdlib structural audit is deterministic and offline; semantic analyze/converge remain agent workflows, not invented CLI commands. Archive historical task numbering before normalization. Retain deployment gates instead of deleting inconvenient acceptance criteria. Source: https://github.com/github/spec-kit/releases/tag/v1.0.6 and the checked-in skill instructions.
