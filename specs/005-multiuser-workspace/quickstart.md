# Quickstart

Run python tools/spec_context.py 005-multiuser-workspace, python tools/spec_audit.py, python tools/check_spec_contexts.py and python -m pytest -q. For the browser install the pinned Playwright version from CI, then node tests/ui.cjs. Inspect runtime/ui-screenshots, including both member languages. These are demonstration data, not production credentials.

On an existing server back up first, update the complete source and run sudo bash install.sh --existing. Sign in as the preserved owner. Create a VPN client in Connections, add a Member in People, and select that profile. In a second private browser verify the member sees only the assigned profile and cannot open users/backups/jobs/native wg-easy. Reset or disable the account and verify its old session fails. Confirm account removal does not claim to revoke exported VPN keys. See docs/accounts.en.md and docs/accounts.ru.md.
