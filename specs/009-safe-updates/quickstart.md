# Quickstart
Run python -m pytest tests/test_update.py tests/test_installer_diagnostics.py -q, python tools/spec_audit.py and python tools/check_spec_contexts.py. Linux CI runs sudo bash tests/update_bootstrap.sh and storage/locking fixtures. Read docs/update.en.md or docs/update.ru.md. Full VPS update and external client acceptance are not inferred from fixtures.
