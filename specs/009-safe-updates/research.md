# Decisions
Archive installations have no Git metadata; use an exact-commit tarball and protected-path extraction. File replacement is atomic per file, not for the entire release; a persistent journal and saved candidate recover interrupted copies. Failed deployment does not automatically restore old user state because newly started services may already have accepted changes. Snapshot all writers while stopped, and retain current state before explicit rollback. Root-only update storage protects keys. no space left on device refers to blocks/inodes/quota on Docker/containerd storage, not website DNS.
