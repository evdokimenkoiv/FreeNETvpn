# Decisions and alternatives

Decision: local HTML/CSS/JS avoids frontend supply-chain/runtime build requirements. FastAPI sessions use Secure/HttpOnly/SameSite cookies and Origin+CSRF validation. Root operations run in a separate systemd Unix agent so backup can restart the web container without losing its worker. Rejected: Docker socket in the web container, arbitrary shell API, external QR generators and fabricated traffic metrics. A bounded serialized queue and cross-process operation lock protect state; a separate reentrant wg-easy adapter lock prevents concurrent SQLite login writes. VLESS adds gRPC while preserving the original WS UUID. Presets derive exports without rotating identities. Evidence: tests/test_dashboard.py, tests/ui.cjs and both Linux packet suites.
