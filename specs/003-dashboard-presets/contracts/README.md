# Local agent protocol

Transport: one UTF-8 JSON line per connection over /run/freenetvpn/control.sock (group 10001, mode 0660); no TCP listener. Maximum request 65536 bytes including newline, socket timeout 35 seconds. Envelope: {token, method, data}; token is the private 64-hex-character token. Methods: snapshot (no input), submit (job request), export (protocol/name/optional format, unknown export fields rejected). Success: {ok:true,data:...}; failure: {ok:false,error:string}, maximum error length 300. The web bridge translates agent rejection to HTTP 400 and connection/parse failure to 503.

Job input requires operation and request_id. Allowed optional fields: protocol/name/preset/username/password. Unknown fields are rejected. Protocol must be enabled except backup.create. Client names and protected legacy identity follow data-model.md. wireguard.connect requires protocol=wireguard and username [A-Za-z0-9_-]{1,64}, password length 1..1024. Duplicate retained request_id returns the previous job. Queue-full is an explicit error. Operation catalog and HTTP contract are in http.json. tests/test_contracts.py exercises the actual Unix handler with in-memory streams (without starting a privileged server), not an imitation handler.
