# Implementation plan

Use a bounded background sampler in the root Unix-socket controller. Read only approved Compose containers and their Linux network namespaces; no keys or remote addresses leave the collector. Persist aggregate samples atomically under data/control. Separate on-demand maintenance inspection from ordinary overview polling. Use fixed argv and timeouts, no shell, paths or arbitrary URLs from HTTP. Reuse admin authorization, CSRF protection, bounded job queue and operation lock. Preview cleanup with a random short-lived token, consume once at execution and record measured disk change. Keep Docker socket out of the web service. Add seven-day journal/cache cleanup only; preserve all application state. Test parsers, resets, failure states, token replay, member denial and both browser languages before deploying with an off-server backup.
