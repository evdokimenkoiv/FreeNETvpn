# Decisions

Docker bridge namespace counters avoid exposing new public metric ports or changing protocol credentials. Count only eth interfaces, excluding tunnel and loopback interfaces to avoid counting both on the same container. IKEv2 and L2TP use one row for bytes. Recent handshakes and inbound established TCP sockets have different meanings and must be labelled. Docker builder prune supports an until filter; omit --all and never use system/volume prune. journalctl vacuum-time affects archived files only; do not rotate active logs as part of cleanup. Configure bounded Docker log rotation for future container creation. GitHub branch-head comparison is an available source revision, not a compatibility guarantee. References: https://docs.docker.com/reference/cli/docker/builder/prune/ and https://www.freedesktop.org/software/systemd/man/latest/journalctl.html .
