# Decisions
The reported screenshot has DOMAIN equal to WG_DOMAIN. This fails local configuration validation before DNS is queried. getent ahostsv4 uses the server resolver; missing results can mean absent A records, delayed caching or a resolver problem, so avoid falsely diagnosing propagation. curl exit 6 indicates name resolution, 7 connection failure, 28 timeout and 60 certificate verification. HTTP 502/503 implicates an unavailable backend; unexpected public admin status is a separate authentication check. Shared IP addresses are supported, duplicate hostnames are not. Read-only diagnostics must remain runnable before Docker is installed.
